## 📥 التثبيت

1. نزّل ملف APK من [صفحة الإصدارات](https://github.com/aseer-coder/luna/releases/latest).
2. انقله إلى التلفاز (فلاش USB أو تطبيق نقل ملفات).
3. اسمح بالتثبيت من مصادر غير معروفة، ثم ثبّت التطبيق.
4. من الإعدادات داخل Luna اختر **لانشر افتراضي** لتعيينه واجهة رئيسية.
